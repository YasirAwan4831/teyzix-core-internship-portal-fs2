## 🚀 Getting Started

### 📋 Prerequisites

Make sure you have the following installed before starting:

![Node.js](https://img.shields.io/badge/Node.js-≥18.0.0-339933?style=flat-square&logo=node.js&logoColor=white)
![npm](https://img.shields.io/badge/npm-≥9.0.0-CB3837?style=flat-square&logo=npm&logoColor=white)
![MongoDB](https://img.shields.io/badge/MongoDB-Running_Locally-47A248?style=flat-square&logo=mongodb&logoColor=white)
![Git](https://img.shields.io/badge/Git-Installed-F05032?style=flat-square&logo=git&logoColor=white)

---

### ⚡ Installation

**1️⃣ Clone the Repository**

```bash
git clone https://github.com/YasirAwan4831/teyzix-core-portal.git
cd teyzix-core-portal
```

**2️⃣ Setup Environment Variables**

```bash
cp .env.example .env
# Edit .env and add your MongoDB URI and PORT
```

**3️⃣ Install Server Dependencies**

```bash
cd server
npm install
```

**4️⃣ Seed the Database**

```bash
npm run seed
```

**5️⃣ Start the Backend Server**

```bash
npm run dev
```

**6️⃣ Install Client Dependencies**

```bash
cd ../client
npm install
```

**7️⃣ Launch the Frontend**

```bash
npm run dev
```

> 🎉 **App will be live at** → `http://localhost:5173`
